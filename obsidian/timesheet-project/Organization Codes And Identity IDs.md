# Organization Codes And Identity IDs

> Implemented on `develop` in commit `3891440`, 7 October 2026.

## Organization Code

- Each tenant receives a unique seven-character code: four uppercase
  alphanumeric characters derived from the organization name, followed by three
  digits. If the name does not provide four ASCII letters or digits, the slug
  supplies the remaining prefix characters.
- Identity chooses a cryptographically random starting suffix and searches the
  000–999 range for an unused code. A unique database index enforces uniqueness.
- Tenant creation returns the code. Login sends `organizationCode`, email, and
  password; a successful response includes the internal `tenantId` used by the
  frontend for authenticated service calls and session renewal.
- `AIYA001` is reserved for the Platform Admin tenant. Existing tenants receive
  codes in the `AddTenantOrganizationCode` migration before the column becomes
  required and unique.

## Identity GUIDs

- Newly generated Identity IDs use `GuidGenerator.NewGuid` from
  `Aiyara.Timesheet.Component.Abstractions` (UUID version 8).
- Identity selects `regionId` and `shardId` independently with a
  cryptographically secure random source; both values are in the inclusive
  range 1–9 and occupy the first two UUID bytes.
- The fixed Platform Admin tenant ID is a reserved bootstrap identifier and is
  not generated by this helper.
