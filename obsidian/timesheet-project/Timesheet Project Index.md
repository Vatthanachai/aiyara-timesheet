# Aiyara Timesheet Project

> Repository snapshot: 5 October 2026

## Purpose

`Aiyara.Timesheet` is an early-stage, distributed timesheet application. Its repository contains a Nuxt frontend, separate identity and timesheet ASP.NET Core APIs, and an Aspire AppHost intended to orchestrate them during local development.

## Repository Facts

- Solution: `Aiyara.Timesheet.slnx`
- Shared target framework: `.NET 10` with nullable reference types and implicit usings enabled.
- Frontend: Nuxt 4 / Vue 3, managed with Bun.
- Local orchestration: .NET Aspire AppHost.
